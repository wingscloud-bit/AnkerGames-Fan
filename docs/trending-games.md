# Trending Games

The Trending section provides a way to discover games receiving recent attention on AnkerGames.

## Why Trending Matters

A large library contains many games that users may never encounter through a normal search.

A trending section provides another discovery path by highlighting titles that are attracting activity.

## Weekly Activity

Trending information focuses on recent activity rather than only lifetime popularity.

This makes it possible to discover games that are currently receiving attention even if they are not among the most established titles in the entire library.

## Discovering New Games

The Trending page can be useful when you want recommendations without having a particular title in mind.

Instead of searching for something specific, browse the current activity and explore games that catch your interest.

## Trends Change

Trending lists are dynamic.

A game's position or level of activity can change as users interact with different titles over time.

For current information, refer directly to the AnkerGames Trending page.
