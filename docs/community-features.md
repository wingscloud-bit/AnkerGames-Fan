# Community Features

AnkerGames includes features that extend beyond basic game browsing.

These features help users personalize their experience, keep track of games, interact with the platform, and stay informed about relevant changes.

## User Profiles

User profiles provide members with a personal area containing information about their activity on the platform.

Profile areas can include:

* Overview
* Liked games
* Game History
* Watchlist
* Statistics
* Achievements and badges
* Recent activity

## Liked Games

Users can save games they like through the Like feature.

The Liked section provides a convenient place to revisit those titles.

## Watchlist

The Watchlist is designed for games users want to keep track of.

Updates related to watchlisted games can also be surfaced through the notification system.

## Game History

Game History provides a record of recently visited game pages.

This is useful when a user wants to return to a title they recently viewed.

## Notifications

The internal notification system can inform users about relevant events, including:

* Updates to watchlisted games
* Report status changes
* Game request updates
* Administrative announcements

Users can manage notification preferences through their account settings.

## Achievements and Badges

Profiles can include achievements and badges that represent different aspects of a user's activity and participation.

These features add a community-oriented layer to the platform.

## Game Requests

The request system allows users to suggest games for consideration.

Requests can be subject to platform rules, voting, review, and availability considerations.

## Reporting

Users can report problems when they encounter issues with game information or other supported areas of the platform.

Reporting helps bring potential problems to the attention of the team responsible for maintaining the platform.

## Community Participation

Together, profiles, notifications, requests, reports, likes, watchlists, and other features make AnkerGames more than a simple game index.

They provide different ways for users to interact with and personalize their experience.
