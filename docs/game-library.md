# Game Library

The AnkerGames Game Library is the central place for exploring the platform's collection of PC games.

A large library can be difficult to navigate when every title is presented in the same way. AnkerGames provides several ways to browse the collection so users can approach the library according to what they are looking for.

## Searching

Search is useful when you already know the name of a game or have a specific title in mind.

For broader discovery, browsing and filtering options can be more useful than searching for an exact title.

## Browsing

The library can be explored through different categories and filters.

Depending on the available options, users can narrow the library using:

* Alphabetical browsing
* Developer
* Genre
* Size
* Release year
* Game mode

These options allow users to move from a very large collection to a smaller group of relevant games.

## Game Entries

Game entries provide an overview of individual titles.

Depending on the game, an entry can provide information such as the title, artwork, release information, version, size, and other relevant details.

## Discovery

The library is not only intended for finding a known game.

Browsing by genre, developer, year, popularity, recent activity, or other categories can also help users discover games they may not have encountered before.

## Random Discovery

Users who do not have a particular game in mind can use the Random Game Generator to discover a title from the library.

This provides a simple alternative to manually browsing through hundreds or thousands of entries.

# `docs/game-search.md`

# Game Search

The search system is designed to help users locate games without manually browsing the entire library.

## When to Use Search

Search is most useful when you know:

* The complete game title
* Part of the title
* A distinctive word from the title

If you do not know the title, browsing by genre, developer, publisher, year, or other categories may be more effective.

## Search Strategy

Start with the simplest version of the title you remember.

For example, if you remember a game contains a particular word, searching for that word can be easier than trying to remember the complete official title.

Once you find a possible match, review the game information to confirm that it is the title you were looking for.

## Search vs. Browsing

Search and browsing serve different purposes.

**Search** is best when you already know what you want.

**Browsing** is better when you want to explore possibilities.

Using both approaches makes a large game library easier to navigate.

# `docs/game-filters.md`

# Game Filters

Filters help reduce the number of games displayed in a large library.

Instead of manually examining every game, users can combine different criteria to narrow the results.

## Available Categories

Depending on the current implementation, the library can be filtered by categories such as:

* Alphabet
* Developer
* Genre
* Size
* Year
* Game mode

## Genre

Genre filtering is useful when you already know the type of game you want to explore.

For example, someone interested in strategy games can focus on that genre instead of browsing unrelated titles.

## Developer

Developer filtering allows users to explore games associated with a particular development studio.

This can be useful when looking for additional games from a developer whose work you already enjoy.

## Release Year

Year filtering can help when searching for games from a particular period.

It can also be useful when researching how a genre or game series changed over time.

## Size

Size filtering provides another way to narrow results when storage requirements are an important consideration.

## Game Mode

Game mode can help distinguish between different types of play experiences.

## Combining Filters

Using several filters together can make discovery considerably more precise.

For example, a user could combine a genre with a release year or developer to create a much smaller set of results.

# `docs/collections.md`

# Collections

Collections provide a way to group games around a common theme, category, or subject.

Instead of discovering titles individually, users can explore a group of related games from one place.

## Why Collections Are Useful

Collections are particularly useful for discovery.

A user might know that they want to explore a particular type of game but not know which individual titles to search for.

A collection can provide a starting point.

## Exploring a Collection

When viewing a collection, users can browse the games included in it and open individual game pages for additional information.

Collections can therefore act as a bridge between broad discovery and individual game research.

## Community Discovery

Collections can also make it easier to share groups of games around a particular interest.

As the platform develops, collections can provide an organized way of navigating different parts of the library.

# Trending Games

The Trending section provides a way to discover games receiving recent attention on AnkerGames.

## Why Trending Matters

A large library contains many games that users may never encounter through a normal search.

A trending section provides another discovery path by highlighting titles that are attracting activity.

## Weekly Activity

Trending information focuses on recent activity rather than only lifetime popularity.

This makes it possible to discover games that are currently receiving attention even if they are not among the most established titles in the entire library.

## Discovering New Games

The Trending page can be useful when you want recommendations without having a particular title in mind.

Instead of searching for something specific, browse the current activity and explore games that catch your interest.

## Trends Change

Trending lists are dynamic.

A game's position or level of activity can change as users interact with different titles over time.

For current information, refer directly to the AnkerGames Trending page.

# Game of the Day

Game of the Day is a discovery feature displayed on the AnkerGames homepage.

It highlights a selected game and gives visitors an opportunity to discover something without performing a search.

## Why It Exists

Many users visit a game platform looking for something interesting rather than searching for one specific title.

Game of the Day provides a simple entry point for that type of discovery.

## Homepage Discovery

Because it appears on the homepage, Game of the Day can introduce visitors to titles they may otherwise overlook.

It complements other discovery features such as Trending, Collections, and the Random Game Generator.

## Exploring the Featured Game

Visitors can open the featured game and explore its available information, including the details provided on its game page.

The selected game changes over time, making the homepage an evolving discovery point.

# Developers & Publishers

The Developers & Publishers section provides another way to explore the AnkerGames library.

Games are created and published by organizations and independent developers with different styles, genres, and histories.

## Why Browse by Developer?

If you enjoy a particular developer's games, exploring their other titles can be an efficient way to discover something new.

Developer browsing also provides useful context for understanding connections between different games.

## Publishers

Publishers can also be used as a discovery category.

A publisher may be associated with games across several genres or development studios, so browsing publishers can reveal titles that might not otherwise appear together.

## Discovery Through Companies

Browsing developers and publishers changes the way users approach the library.

Instead of starting with a game title, users can start with the organization behind the game and explore its catalog.

## Keeping Information Organized

A dedicated Developers & Publishers section makes it easier to connect game information with the companies responsible for creating or publishing those games.

# `docs/community-features.md`

# Community Features

AnkerGames includes features that extend beyond basic game browsing.

These features help users personalize their experience, keep track of games, interact with the platform, and stay informed about relevant changes.

## User Profiles

User profiles provide members with a personal area containing information about their activity on the platform.

Profile areas can include:

* Overview
* Liked games
* Game History
* Watchlist
* Statistics
* Achievements and badges
* Recent activity

## Liked Games

Users can save games they like through the Like feature.

The Liked section provides a convenient place to revisit those titles.

## Watchlist

The Watchlist is designed for games users want to keep track of.

Updates related to watchlisted games can also be surfaced through the notification system.

## Game History

Game History provides a record of recently visited game pages.

This is useful when a user wants to return to a title they recently viewed.

## Notifications

The internal notification system can inform users about relevant events, including:

* Updates to watchlisted games
* Report status changes
* Game request updates
* Administrative announcements

Users can manage notification preferences through their account settings.

## Achievements and Badges

Profiles can include achievements and badges that represent different aspects of a user's activity and participation.

These features add a community-oriented layer to the platform.

## Game Requests

The request system allows users to suggest games for consideration.

Requests can be subject to platform rules, voting, review, and availability considerations.

## Reporting

Users can report problems when they encounter issues with game information or other supported areas of the platform.

Reporting helps bring potential problems to the attention of the team responsible for maintaining the platform.

## Community Participation

Together, profiles, notifications, requests, reports, likes, watchlists, and other features make AnkerGames more than a simple game index.

They provide different ways for users to interact with and personalize their experience.
