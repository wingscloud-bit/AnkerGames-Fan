# Game Library

The AnkerGames Game Library is the central place for exploring the platform's collection of PC games.

A large library can be difficult to navigate when every title is presented in the same way. AnkerGames provides several ways to browse the collection so users can approach the library according to what they are looking for.

## Searching

Search is useful when you already know the name of a game or have a specific title in mind.

For broader discovery, browsing and filtering options can be more useful than searching for an exact title.

## Browsing

The library can be explored through different categories and filters.

Depending on the available options, users can narrow the library using:

* Alphabetical browsing
* Developer
* Genre
* Size
* Release year
* Game mode

These options allow users to move from a very large collection to a smaller group of relevant games.

## Game Entries

Game entries provide an overview of individual titles.

Depending on the game, an entry can provide information such as the title, artwork, release information, version, size, and other relevant details.

## Discovery

The library is not only intended for finding a known game.

Browsing by genre, developer, year, popularity, recent activity, or other categories can also help users discover games they may not have encountered before.

## Random Discovery

Users who do not have a particular game in mind can use the Random Game Generator to discover a title from the library.

This provides a simple alternative to manually browsing through hundreds or thousands of entries.
