# Frequently Asked Questions

## What is AnkerGames?

AnkerGames is a PC gaming platform focused on organizing game information and making it easier for users to discover and explore games.

The platform combines a large game library with search, filtering, browsing, discovery, and community features.

## What type of games does AnkerGames cover?

AnkerGames currently focuses on **PC games**.

The library contains games from different genres, developers, publishers, release periods, and game modes.

## How can I find a specific game?

The quickest option is usually the search function.

You can also browse the game library using available filters and categories. Depending on what you are looking for, you can narrow games by factors such as alphabet, developer, genre, size, year, and game mode.

## What is Browse by Letter?

Browse by Letter provides an alternative way to explore the game library.

Instead of entering a complete title into the search field, users can select a letter and browse games beginning with that letter.

This can be useful when you remember only part of a game's name or simply want to explore titles alphabetically.

## What are Collections?

Collections group related games together around a particular theme or category.

Collections can make it easier to discover several related titles without searching for each game individually.

## What is Game of the Day?

Game of the Day highlights a selected game on the AnkerGames homepage.

It provides another way to discover games without having to search for a particular title.

## What is the Random Game Generator?

The Random Game Generator provides a simple way to discover a game when you do not have a specific title in mind.

Instead of browsing manually, users can let the generator select a game from the available library.

## What is the Trending page?

The Trending section focuses on games receiving attention based on recent activity.

It is useful for discovering games that are currently attracting interest within the platform.

## What is the Recent Updates page?

Recent Updates provides a way to see games that have recently received updates on the platform.

This can be useful for users who want to keep up with changes to games they are interested in.

## Can I find games by developer or publisher?

Yes.

The Developers & Publishers section provides a way to explore companies and developers represented in the game library.

This is particularly useful when you enjoy games from a particular developer or publisher and want to discover other titles associated with them.

## What information can a game page contain?

A game page can include information such as:

* Game title
* Poster or artwork
* Release information
* Developer
* Version information
* Game edition
* Description
* Screenshots
* Trailer information
* System requirements
* Related games
* Game features
* Additional content
* Notes
* Community interaction

The exact information available can vary between games.

## What is the Watchlist?

The Watchlist allows users to save games they want to keep track of.

It can be useful for creating a personal list of games that you want to revisit later.

## What is Game History?

Game History keeps track of recently visited games on a user's profile.

This makes it easier to return to games that were previously viewed without searching for them again.

## What is the Liked section?

The Liked section contains games that a user has marked as liked.

Users can also receive update notifications for games they are following through their profile features.

## What are notifications?

AnkerGames includes an internal notification system for important account and platform events.

Depending on the event, notifications can include:

* Updates to watchlisted games
* Report status updates
* Game request updates
* Administrative announcements

Notification settings can be managed through the user's account settings.

## Can users request games?

AnkerGames has a game request system that allows users to suggest games for consideration.

Requests may go through a community voting and review process before being approved or rejected.

Request availability and limits can change over time, so users should check the current request system for the latest rules.

## Why can a game request be rejected?

Not every requested game can necessarily be added.

Requests may be rejected for a variety of reasons, including availability, technical considerations, duplicate requests, or other platform-specific requirements.

A rejection does not necessarily mean the game itself is unavailable everywhere.

## What should I do if information on a game page is outdated?

If you notice an outdated version or another problem with a game page, use the appropriate reporting option available on the platform.

Providing accurate information helps the team review and update the relevant page.

## Can I report a problem?

Yes.

AnkerGames provides reporting functionality for problems with game pages and other relevant issues.

When reporting a problem, providing specific information can make it easier to investigate.

## Is this GitHub repository official support?

No.

This repository is a community resource and should not be treated as an official support channel.

For account, website, or platform-related assistance, use the official AnkerGames website and its available community/support channels.
