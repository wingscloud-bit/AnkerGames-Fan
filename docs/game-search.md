# Game Search

The search system is designed to help users locate games without manually browsing the entire library.

## When to Use Search

Search is most useful when you know:

* The complete game title
* Part of the title
* A distinctive word from the title

If you do not know the title, browsing by genre, developer, publisher, year, or other categories may be more effective.

## Search Strategy

Start with the simplest version of the title you remember.

For example, if you remember a game contains a particular word, searching for that word can be easier than trying to remember the complete official title.

Once you find a possible match, review the game information to confirm that it is the title you were looking for.

## Search vs. Browsing

Search and browsing serve different purposes.

**Search** is best when you already know what you want.

**Browsing** is better when you want to explore possibilities.

Using both approaches makes a large game library easier to navigate.
