# PC Gaming Tools

PC gaming involves more than choosing games. Players often use additional tools to organize libraries, monitor hardware, troubleshoot problems, manage files, and improve their overall experience.

This document provides categories of useful tools rather than promoting a specific product.

## Game Library Management

Library-management tools can help organize information about installed games and purchased titles.

Useful capabilities may include:

* Game categorization
* Library search
* Metadata management
* Play-time tracking
* Installation management

## Hardware Monitoring

Hardware-monitoring software can help users understand how their PC is performing while running demanding applications.

Common information includes:

* CPU usage
* GPU usage
* Memory usage
* Temperatures
* Frame rates

## Storage Management

Large modern games can require significant storage space.

Useful storage-management practices include:

* Checking available disk space
* Identifying large files
* Removing unused applications
* Keeping adequate free space for updates

## Screenshot and Recording Tools

PC gamers may also use screenshot and recording software to capture gameplay, tutorials, technical problems, or memorable moments.

## Troubleshooting Resources

When a game does not behave as expected, useful troubleshooting steps can include:

1. Check the game's system requirements.
2. Confirm that required drivers are current.
3. Restart the application.
4. Check available storage.
5. Review official documentation.
6. Search for known issues.
7. Report the problem through the appropriate support channel.
