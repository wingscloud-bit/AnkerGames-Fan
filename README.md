## Why Game Discovery Matters

Modern game libraries contain thousands of titles across many genres, developers, release years, and game modes. Finding something specific can therefore become difficult when relying only on a basic search box.

Useful discovery tools can help players narrow down their options, discover older games they may have missed, and find titles based on different interests.
